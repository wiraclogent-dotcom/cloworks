The Requests page shows the same work in three ways. Use the switcher at the top of the page to change views.

## Board

The board groups requests into columns by status: **Requested**, **On progress**, **First look**, and **Done**. Cancelled requests have no column on the board.

1. Find the card you want to move.
2. Drag it into another column.

Creatives, leads, and admins can move cards. Requesters can see the board but cannot move cards.

## Table

The table lists requests in rows, one per request. Use it when you need to scan many requests at once.

## Calendar

The calendar places open requests on their deadline day. Requests with no deadline appear on today.

1. Find the request you want to reschedule.
2. Drag it to another day.

Moving a card on the calendar changes its deadline. Creatives, leads, and admins can reschedule requests.

To narrow what you see in any view, use the filters. See [Today's overview, search, and filters](/help/todays-overview-search-filters).
