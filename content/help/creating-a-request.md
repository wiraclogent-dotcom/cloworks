Use a request to ask the creative team for a piece of work. Fields marked * are required.

## Steps

1. On the Requests page, select **New request**.
2. Fill in **Title** and the other request details:
   - **Title** *: a short name for the work.
   - **Brief link**: a link to the brief, if you have one.
   - **Notes**: anything the creative team should know.
   - **Brand** *: choose from the list.
   - **Division** *: choose from the list.
   - **Deadline**: when the work is needed.
3. Under **Motion**, answer **Does this task need motion?**
   - **No**: design only.
   - **Yes, needs motion**: the motion or video editor will also work on it.
4. Select **Create request**.

The form also shows a short "What happens next" panel. Select **Cancel** to leave without creating the request.
