The **Brands, divisions and request types** page holds the lists that fill the dropdowns on request and project forms.

## Lists

- **Brands**: the brands a request or project can belong to.
- **Divisions**: the divisions a request can belong to.
- **Request types**: the kinds of work a request can be.

## Add a request type

1. Select your profile picture at the top right, choose **Account settings**, then choose **Lists** under **Administration**.
2. Select **Add request type**.
3. Enter the **Name**, and any **Aliases (comma separated)** people might type instead.
4. Enter the **Field schema (JSON array)** if the request type needs extra fields. Leave it empty for the standard form.
5. Save.
