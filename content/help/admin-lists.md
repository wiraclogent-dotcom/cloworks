The **Brands, divisions and request types** page holds the lists that fill the dropdowns on request, project, Content Plan and Library forms. To open it, select your profile card at the bottom left of the sidebar, choose **Settings**, then the **Lists** tab.

Under each item you see what uses it, for example *508 requests · 7 projects*, or *Not used yet*.

## Brands

Brands appear on requests, projects, Content Plan channels and Library items.

- **Add a brand**: type its name under the list and select **Add brand**.
- **Rename**: change the name in its box and select **Rename**.
- **Colour**: select the coloured dot in front of the name and pick one of the 11 colours. Every brand tag in Clowork uses it straight away.

## Divisions

A division is the team a request comes from. Add and rename divisions here. Which divisions get a lane on the Marketing Calendar, with their colour, order and leads, is set on the **Marketing calendar** tab.

## Request types and their fields

A request type is what people can ask for, such as *General Design* or *Social Media*. Select a type to open it.

A type can ask extra questions on the new request form. Each question is a row:

- **Label**: the question people see, for example *Platform*.
- **Type**: *Short text*, *Choice list* (people pick one of your choices), *Checkbox* or *Link*.
- **Required**: people must answer before they can send the request (not for checkboxes).
- **Choices** (Choice list only): type a choice and press Enter to add it; select × on a choice to remove it.

Use ↑ and ↓ to change the order, **Add field** for a new question and × at the end of a row to remove one. Nothing changes until you select **Save type**.

Renaming a question keeps the answers already given. If you remove a question that requests have answered, Clowork asks first: the answers are kept but no longer shown. Adding the same question back shows them again.

To add a type, fill in **Add request type** at the bottom of the card.

## Archive, restore and delete

Select **⋯** at the end of a row:

- **Archive** hides the item from forms for new work: new requests, projects, Content Plan channels and Library items. Everything already using it keeps it and still shows it, and filters still find it. An archived division also leaves the Marketing Calendar.
- Archived items wait under **Archived** at the bottom of their card. Open it and choose **Restore** to bring one back.
- **Delete** is only offered for an item nothing uses, for example a name typed by mistake. It can't be undone. Anything in use can only be archived.
