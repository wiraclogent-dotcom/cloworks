## Today's overview

Above the board, **Today's overview** shows four numbers and a short greeting:

- **Open requests**: everything not yet Done or Cancelled.
- **Due today**: open requests with a deadline today.
- **Overdue**: open requests whose deadline has passed.
- **Done today**: requests marked Done today.

Use it as a quick check before you start your day.

## Search

Use the **Search** box on the Requests page to find requests by typing part of their title.

## Filters

Select **Filters** to open the filter panel. Each filter is set to **All** (or **Any**) by default, so you only change the ones you need.

1. Choose the values you want to filter by.
2. Select **Apply**.

Filters apply to the current view, so the board, table, and calendar all show the same filtered set.
