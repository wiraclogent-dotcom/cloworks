A project groups the work for one brand or campaign. Projects appear on the Projects page, grouped by brand, with the soonest due first.

## Create a project

1. Open **Projects** from the sidebar.
2. Select **New project**.
3. Fill in the fields. Fields marked * are required:
   - **Title** *
   - **Sub title**
   - **Brand**
   - **Owner** *
   - **Status** *: one of **Not started**, **In progress**, **In review**, **Done**, or **On hold**.
   - **Start date** and **Due date**
   - **File link**: a link to the project's files.
4. Save the project.

## Edit a project

Select the project, then change its details on the edit page.

## Project overview

Select a project's title on the Projects page to open its overview. It shows:

- **Items**, **Details**, **Completed** and **Last due date** at the top. **Completed** is the share of details that are finished.
- **Progress**: how many details are at each step. Design projects count stages (**Not Started** through **Final Artwork**; **Canceled** details are left out of **Completed**). Tracker projects count statuses instead, and a detail is finished when it is **Done**.
- **Timeline by item**: one bar per item, from its earliest start date to its latest due date.
- **Meetings and milestones**: dated checkpoints for the project.

### Manage meetings and milestones

1. Select **Add milestone**.
2. Enter a name and date, and tick **Done** if it already happened.
3. Select **Add**.

To change one, select the pencil next to it, edit it, then select **Save**. To remove one, select the bin icon, then **Delete** to confirm.

## Project details

Select **All details** on the overview to see every detail in a table: item, detail, owner, stage or status, start and due dates, and file link.

### Add a detail

1. Select **Add detail**.
2. Enter the **Item** name. **Detail**, **Owner**, **Stage** (or **Status** for tracker projects), dates and **File link** are optional.
3. Select **Add detail**. The new row goes to the bottom of the table.

An item and detail name pair must be unique within the project.

### Edit, move or delete a detail

1. Select the pencil at the start of the row. The row's fields become editable and save as you change them.
2. Use the up and down arrows under the item name to move the row.
3. To remove the row, select the bin icon, then **Delete** to confirm. This can't be undone.
4. Select the tick to stop editing.

Projects imported from a sheet keep the stages and statuses you set here when the sheet is imported again.
