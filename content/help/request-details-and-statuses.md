Every request moves through the statuses below. Select a card to open its details.

## Statuses

| Status | Meaning |
|---|---|
| **Requested** | Asked for, not started yet. |
| **On progress** | Someone is working on it. |
| **First look** | A first version is ready for review. |
| **Done** | Finished. |
| **Cancelled** | Stopped. No further work. |

## Moving a request

A request can move between statuses in these ways:

- **Requested** can move to **On progress** or **Cancelled**.
- **On progress** can move back to **Requested**, forward to **First look**, or to **Cancelled**.
- **First look** can move to **Done**, back to **On progress**, or to **Cancelled**.
- **Done** can move back to **On progress**, or to **Cancelled**.
- **Cancelled** is final.

## Marking a request Done

Before a request can be marked **Done**:

1. It needs an assignee. If nobody is assigned, the board asks you to assign someone first.
2. Enter the **output count**: how many pieces of work were delivered.
3. Optionally, add a **design folder link** where the files are kept. It must be a web link.

Requests that are Cancelled cannot be reopened.
