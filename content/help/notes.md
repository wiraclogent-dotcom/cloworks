**Notes** is your own notebook inside Clowork. Open it from **Tools › Notes** in the sidebar. Only you can see your notes: nobody else can open them, admins included.

## Write a note

1. Select **New note**. The note opens on the right.
2. Start typing. The first line becomes the note's title in the list.
3. There is no Save button: Clowork saves about a second after you stop typing. The line under the toolbar says **Saved** with the time of your last edit.

If the connection drops, that line says **Not saved. Retrying…** and keeps trying; your text stays in the note. Don't close the tab until it says **Saved** again.

A new note you leave empty is removed automatically.

## Format text

Use the toolbar above the note, or these shortcuts:

- **Title, Heading, Subheading, Body**: the **Text style** button (T) at the left of the toolbar, or type `# `, `## ` or `### ` at the start of a line.
- **Bold**: ⌘B (Ctrl+B on Windows). **Italic**: ⌘I. **Underline**: ⌘U. **Strikethrough**: ⌘⇧S.
- **Bulleted list**: type `- ` at the start of a line. **Numbered list**: type `1. `. **Checklist**: type `[ ] `.
- **Link**: select the text, then the link button or ⌘K, and paste the address. Web addresses and email links (`mailto:`) work. Select a link in a note to open it in a new tab.

In a list, **Tab** indents an item and **Shift+Tab** moves it back. Tick a checklist item to mark it done.

Notes hold text only. When you paste from a website or a document, the formatting above is kept; pictures, tables and colours are left out.

## Folders

- **All Notes** shows every note you have.
- Select **New folder** to make one, for example *Meeting* or *Content ideas*. New notes go into the folder you have open.
- To move a note, open it, select **⋯** in the toolbar, then **Move to folder**.
- To rename or delete a folder, select **⋯** next to its name. Deleting a folder moves its notes to **Recently Deleted**.

On a phone, select **Folders** above the list to switch folders.

## Pin and search

- Select **⋯ › Pin note** to keep a note at the top of the list under **Pinned**.
- Type in **Search** to find notes by any word in their title or text. The search looks inside the folder you have open; open **All Notes** to search everything.

## Recently Deleted

Deleted notes stay in **Recently Deleted** for 30 days, then they are removed for good.

- Open the note and select **Restore** to bring it back. It returns to its folder, or to All Notes if that folder no longer exists.
- Select **Delete now** to remove one note straight away, or **Empty** to remove everything in Recently Deleted.
